Tipos de listas en HTML

En HTML existen diferentes tipos de listas. A continuación se muestran cinco ejemplos con 10 elementos cada uno.

1. Lista desordenada

Se utiliza la etiqueta <ul> y cada elemento se escribe con <li>.

Código:


<ul>
    <li>Manzana</li>
    <li>Naranja</li>
    <li>Plátano</li>
    <li>Fresa</li>
    <li>Mango</li>
    <li>Sandía</li>
    <li>Melón</li>
    <li>Uva</li>
    <li>Piña</li>
    <li>Papaya</li>
</ul>

Resultado:

  • Manzana
  • Naranja
  • Plátano
  • Fresa
  • Mango
  • Sandía
  • Melón
  • Uva
  • Piña
  • Papaya

2. Lista ordenada

Se utiliza la etiqueta <ol> y cada elemento se escribe con <li>.

Código:


<ol>
    <li>Despertarse</li>
    <li>Bañarse</li>
    <li>Vestirse</li>
    <li>Desayunar</li>
    <li>Preparar la mochila</li>
    <li>Salir de casa</li>
    <li>Tomar el transporte</li>
    <li>Llegar a la escuela</li>
    <li>Entrar al salón</li>
    <li>Comenzar las clases</li>
</ol>

Resultado:

  1. Despertarse
  2. Bañarse
  3. Vestirse
  4. Desayunar
  5. Preparar la mochila
  6. Salir de casa
  7. Tomar el transporte
  8. Llegar a la escuela
  9. Entrar al salón
  10. Comenzar las clases

3. Lista de definición

Se utiliza <dl> para la lista, <dt> para el término y <dd> para su definición.

Código:


<dl>

    <dt>HTML</dt>
    <dd>Lenguaje utilizado para crear páginas web.</dd>

    <dt>CSS</dt>
    <dd>Lenguaje utilizado para dar estilos a las páginas web.</dd>

    <dt>JavaScript</dt>
    <dd>Lenguaje utilizado para agregar interactividad.</dd>

    <dt>Internet</dt>
    <dd>Red mundial que conecta dispositivos.</dd>

    <dt>Navegador</dt>
    <dd>Programa utilizado para visitar páginas web.</dd>

    <dt>Servidor</dt>
    <dd>Computadora que proporciona servicios a otras computadoras.</dd>

    <dt>Página web</dt>
    <dd>Documento que se puede visualizar en un navegador.</dd>

    <dt>URL</dt>
    <dd>Dirección que permite localizar un recurso en Internet.</dd>

    <dt>Enlace</dt>
    <dd>Elemento que permite ir a otra página o recurso.</dd>

    <dt>Etiqueta</dt>
    <dd>Elemento utilizado para estructurar contenido HTML.</dd>

</dl>

Resultado:

HTML
Lenguaje utilizado para crear páginas web.
CSS
Lenguaje utilizado para dar estilos a las páginas web.
JavaScript
Lenguaje utilizado para agregar interactividad.
Internet
Red mundial que conecta dispositivos.
Navegador
Programa utilizado para visitar páginas web.
Servidor
Computadora que proporciona servicios a otras computadoras.
Página web
Documento que se puede visualizar en un navegador.
URL
Dirección que permite localizar un recurso en Internet.
Enlace
Elemento que permite ir a otra página o recurso.
Etiqueta
Elemento utilizado para estructurar contenido HTML.

4. Lista ordenada con letras

Se utiliza <ol type="A"> para mostrar los elementos utilizando letras mayúsculas.

Código:


<ol type="A">
    <li>Matemáticas</li>
    <li>Español</li>
    <li>Inglés</li>
    <li>Historia</li>
    <li>Geografía</li>
    <li>Biología</li>
    <li>Química</li>
    <li>Física</li>
    <li>Informática</li>
    <li>Educación física</li>
</ol>

Resultado:

  1. Matemáticas
  2. Español
  3. Inglés
  4. Historia
  5. Geografía
  6. Biología
  7. Química
  8. Física
  9. Informática
  10. Educación física

5. Lista ordenada con números romanos

Se utiliza <ol type="I"> para mostrar los elementos utilizando números romanos.

Código:


<ol type="I">

    <li>Segundo organizar la información</li>

    <li>Octavo guardar el archivo</li>
    <li>Noveno entregar el trabajo</li>
    <li>Décimo presentar el proyecto</li>
</ol>

  4. Cuarto revisar la información
  5. Quinto corregir errores
  6. Sexto agregar imágenes
