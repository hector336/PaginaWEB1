Etiquetas Semánticas de HTML

Ejemplos de las principales etiquetas semánticas.

¿Qué son las etiquetas semánticas?

Las etiquetas semánticas son elementos de HTML que indican claramente qué función cumple cada parte de una página web.

Algunos ejemplos son: <header>, <nav>, <main>, <section>, <article>, <aside> y <footer>.

1. <header>

Representa la cabecera de una página o de una sección.

Código:







Mi página web


Bienvenido a mi página.

Semánticas
