Formulario de Inicio de Sesión



Guía de Atributos Utilizados en la Página

Atributo Valor en el Ejemplo ¿Qué hace exactamente?
type "password" / "email" Define el comportamiento del campo. "password" oculta el texto con puntos y "email" valida que el texto tenga una estructura de correo electrónico válida (ejemplo@dominio.com).
id "clave" / "correo" Es el identificador único del elemento. Sirve para enlazar el campo con su etiqueta <label> a través del atributo "for".
name "password" / "email" Es el nombre de la variable que el servidor (backend) leerá para procesar los datos que el usuario escribió.
required (No requiere valor) Hace que el campo sea obligatorio. El navegador impedirá enviar el formulario si la casilla está vacía.
placeholder "Escribe tu contraseña" Muestra un texto sugerido de fondo gris claro dentro del cuadro, el cual desaparece automáticamente en cuanto el usuario empieza a escribir.
minlength "8" Establece el límite mínimo de caracteres obligatorios. Si el usuario escribe menos de 8 caracteres, el navegador mostrará un error.
maxlength "20" Establece el límite máximo de caracteres permitidos. El navegador físicamente bloqueará el teclado e impedirá escribir más allá del número 20.
autocomplete "current-password" Le indica de forma explícita al navegador y a los gestores de contraseñas que este es el campo de la clave actual del usuario para que puedan auto-rellenarla de forma segura.
title "La contraseña debe tener..." Agrega una descripción emergente al pasar el mouse sobre el campo y personaliza el mensaje de error nativo del navegador si no se cumplen los requisitos de longitud.
